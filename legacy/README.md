# legacy/ —— 原始单文件版本存档

`dsp_epwm.tsx` 是本工程重构前的原始实现：一个约 2280 行的单文件 React 组件，
把器件数据、寄存器计算、波形绘制、代码生成与全部 UI 塞在一起。

保留它是为了：

1. **可追溯**：`README.md` 第 6 节列出的每一项修正，都能在这里对上原始代码；
2. **可回退**：需要对照旧行为时不必翻备份；
3. **可对比**：想看清"为什么会生成错误波形"时，这份代码是最好的反面教材。

它**不是**可运行工程的一部分：没有被 `src/` 引用，也不参与构建与测试。
若要单独运行它，需要把它放进一个已配置 React + Tailwind + lucide-react 的宿主项目里。

当前维护的版本见仓库根目录的 `src/`。
